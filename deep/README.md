# 深度版｜从零到能独立投放

> 这不是“科普版的加长版”。它按一名新人真正进入小游戏买量岗位后要面对的工作来组织：先建立测量系统，再开始花钱；先学会定义问题，再学习调账户；先学会判断一笔钱为什么亏，再学习怎么放大一笔赚钱的钱。

**当前版本：深度版 0.4。已完成 40 章：33 章主体训练 + 3 章巨量实操 + 4 章数据练习/解析。** 主线首先聚焦 **抖音小游戏 × 巨量引擎信息流投放**。腾讯广告、磁力引擎与发行人计划会在后续模块单独深入。

## 深度版采用什么写法

每章尽量按同一套训练结构展开：

**1. 这一章解决什么真实问题。** 先给工作场景，而不是先给定义。  
**2. 底层机制。** 解释为什么，不要求死记菜单。  
**3. 决策规则。** 什么情况下做 A，什么情况下做 B。  
**4. 操作清单。** 真正开账户时应该检查什么。  
**5. 数据案例。** 给一组数字，让你学会判断。  
**6. 故障树。** 数据不对时从哪里排查。  
**7. 作业。** 如果没有完成作业，就不算真正学会。

书里的数字案例除非明确标为“平台规定”，否则都是**教学用模拟数据**，目的是训练判断，不代表行业基准。平台事实会尽量引用官方资料并标注核验时间。

## 深度版的一个原则

真正的买量能力不是“记住一个好 CPI 数字”，而是看到一组数据后知道：**现在最可能坏在哪一层；我还缺什么证据；下一次最小成本的实验是什么。**

因此这版书不会给你大量脱离产品和时期的“行业标准答案”。它会更强调条件判断。例如：CTR 低到底是不是素材差，要同时看什么；CPI 高能不能继续跑，要和什么 LTV 比；关键行为应该选哪个，不是看哪个事件听起来更“深”，而是看它是否足够早、足够密、又和长期价值足够相关。
