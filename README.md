# 小游戏买量：从入门到精通

> 一套面向中国小游戏团队的用户获取（UA）实战教材。主线从抖音/巨量引擎开始，逐步扩展到微信/腾讯广告、快手/磁力引擎，并把素材、投放、数据、变现、留存和产品改造放进同一个经营模型里。

**版本：1.0 · 2026-09-16**

这本书不是“后台按钮说明书”。后台会改版，平台术语会变化，但小游戏买量的基本问题长期不变：你花多少钱买来了什么用户，这些用户会不会留下来、会不会产生广告或内购收入，以及你能不能用素材和产品持续复制这种用户。

如果你完全没有投放经验，建议按章节顺序阅读；如果已经开始投放，可以直接从“诊断、放量、深度转化、素材工业化”部分进入。书中以 **抖音小游戏 × 巨量引擎信息流** 作为第一主线，因为素材反馈快、投放链路直观，非常适合作为入门训练场。

## 你会学会什么

读完后，你应该能够独立完成这些事情：理解 CPM、CTR、CVR、CPI/CPA、ARPU/ARPDAU、LTV、ROAS 等指标；判断一个游戏是否具备可买量性；设计第一批素材测试矩阵；搭建第一轮投放计划；读懂“点击便宜但用户差”“CPI 高但回收好”等看似矛盾的数据；用关键行为、付费或 ROI 目标逐步提升用户质量；把买量结果反推到首局、广告点位、关卡、成长与留存设计；建立日/周投放复盘和素材生产系统。

## 全书结构

第一篇建立基本盘：买量到底买什么、单位经济模型怎么计算、漏斗和归因是什么。第二篇讲平台生态，以巨量引擎为主线并介绍腾讯广告、磁力引擎和发行人计划。第三篇讲素材，把广告理解成“用户筛选器”而不是单纯的视频。第四篇进入实操，讲第一轮投放、出价、预算、学习期、诊断和放量。第五篇把投放和游戏产品连接起来。第六篇给出预算实战、经典飞机射击案例、日报周报模板与常见故障排查。

> 重要提醒：平台政策、资质要求、分成比例、账户产品与操作入口会变化。本书对会变化的部分尽量给出“截至版本日期”的官方来源，并建议实际投放前再次核对平台后台与最新官方文档。
