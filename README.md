## 两个版本是什么关系？

**科普版是地图，深度版是驾驶训练。** 科普版不会压缩，也不会降级成几页摘要；它继续作为一套完整的认知框架存在。深度版不会简单复制科普版再把每段扩写三倍，而是重构为职业训练教材：同一个主题会从“是什么”推进到“应该怎么做、什么时候不该做、看到什么数据意味着什么、下一步动作是什么”。

如果你第一次接触买量，可以先快速通读科普版，再进入深度版。如果你已经开始接触真实账户，可以直接进入深度版，并把科普版当作随时回查的概念地图。

## 深度版现在包含什么

目前 41 章分为七个阶段：

**第一阶段：先学会不乱花钱。** 闭环系统、账户工程、事件字典、归因、单位经济、抖音巨量投前全链路、第一轮账户结构。  
**第二阶段：让模型找到对的人。** 学习期、转化目标阶梯、关键行为工程、定向与自动化。  
**第三阶段：素材工程。** 素材实验、前三秒、玩法到脚本、素材衰退、竞品情报。  
**第四阶段：诊断能力。** 晨检顺序、故障树、样本量、停留复制、日报周报。  
**第五阶段：从会投到会经营。** 放量、边际成本、ROI/LTV、现金流、IAA、IAP/混合变现、产品反馈闭环。  
**第六阶段：完整实战。** 飞机射击用户假设、10 个素材方向、3000 元学习预算、1 万元验证预算、七天日志、失败复盘、90 天训练计划。  
**第七阶段：后台实操与数据训练。** 巨量实操地图、第一次真正建广告、事件与数据验收、账户诊断练习、Cohort × LTV 练习及完整解析，并新增“小游戏直投 / 小游戏微端 / 原生 Android APK”三条买量链路专项。

## 深度版的毕业标准

读完并完成练习后，你至少应该能独立完成：投前可买量性判断；账户、资产、事件和数据口径检查；第一轮投放结构设计；素材假设与测试矩阵；按漏斗和 Cohort 读数；区分素材问题、流量问题、产品问题和变现问题；选择激活、关键行为、付费或 ROI 等优化目标；制定暂停、保留、复制、扩量规则；用 LTV 和现金流确定允许成本；完成日报、周复盘与下一轮实验设计。

> 平台后台、政策和产品名称会变化。深度版中涉及抖音小游戏、巨量引擎等会变化的内容，会标注核验日期并优先引用官方资料；“平台事实”与“投放方法论/经验规则”会明确区分。
