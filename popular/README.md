# 科普版｜完整认知版

这就是原来的 28 章版本，**体量保持不变**。它的任务不是把你训练成投手，而是让你对小游戏买量形成一张完整、相对准确的认知地图：钱从哪里花出去，平台怎样分发，素材怎样筛选用户，数据如何反映用户质量，IAA/IAP 怎样回收，留存、LTV、ROI 和放量之间怎样互相制约。

如果你需要和代理商、投手、素材团队、产品团队对话，这一版应该让你不至于只听见一堆术语；如果你要自己真正上手操作账户，则建议通读后进入深度版。

## 阅读路径

第一篇建立基本盘：买量到底买什么、单位经济模型怎么计算、漏斗和归因是什么。第二篇讲平台生态，以巨量引擎为主线并介绍腾讯广告、磁力引擎和发行人计划。第三篇讲素材，把广告理解成“用户筛选器”而不是单纯的视频。第四篇进入实操，讲第一轮投放、出价、预算、学习期、诊断和放量。第五篇把投放和游戏产品连接起来。第六篇给出预算实战、经典飞机射击案例、日报周报模板与常见故障排查。

从 [第 1 章：买量到底是什么](#/chapters/01-what-is-ua) 开始。
